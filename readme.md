# 🚀 Space Kids — Galáxia Kids Solutions

**Um espaço digital inclusivo, acolhedor e interativo para crianças aprenderem no seu próprio ritmo.**

## 📌 Sobre o projeto

O **Space Kids** é um website desenvolvido pela empresa fictícia **Galáxia Kids Solutions**, criada em abril de 2026. O projeto tem como objetivo oferecer recursos digitais voltados a crianças com necessidades específicas, comorbidades e neurodivergências, por meio de atividades simples, interativas e adaptadas.

A proposta surgiu da percepção de que nem todas as crianças encontram atividades adequadas às suas necessidades, preferências e ritmos de aprendizagem. Em alguns contextos, a pressão para acompanhar o ritmo dos outros pode tornar a aprendizagem mais difícil e menos confortável.

Para contribuir com essa realidade, o Space Kids busca proporcionar um ambiente digital tranquilo, acessível e divertido, no qual as crianças possam explorar atividades educativas, reconhecer emoções, desenvolver habilidades e aproveitar momentos de relaxamento.

O website apresenta uma identidade visual inspirada no espaço sideral, com cores suaves, elementos lúdicos e interfaces organizadas. A temática espacial ajuda a criar uma experiência visual agradável, enquanto os recursos interativos tornam a navegação mais dinâmica.

Entre suas funcionalidades estão jogos educativos, atividades de reconhecimento de emoções, pintura digital, desafios de raciocínio, exercícios de respiração e conteúdos audiovisuais relaxantes.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, com o Visual Studio Code como ambiente principal de programação e Git e GitHub como ferramentas de versionamento e armazenamento do código.

## 🎯 Objetivos

### Objetivo geral

Desenvolver uma plataforma digital inclusiva e interativa que ofereça atividades educativas e momentos de relaxamento para crianças com diferentes necessidades, respeitando suas particularidades e seu ritmo de aprendizagem.

### Objetivos específicos

* Criar um ambiente digital acolhedor, organizado e fácil de utilizar.
* Disponibilizar atividades educativas com diferentes propostas.
* Estimular habilidades cognitivas por meio de jogos e desafios.
* Oferecer recursos para reconhecer e expressar emoções.
* Proporcionar atividades de pintura e criatividade.
* Apresentar exercícios de respiração guiada.
* Disponibilizar sons e vídeos com propostas relaxantes.
* Utilizar uma identidade visual infantil inspirada no espaço.
* Desenvolver páginas responsivas para computadores e dispositivos móveis.
* Organizar o conteúdo para facilitar a navegação entre as atividades.
* Disponibilizar uma área administrativa para organização e gerenciamento das informações do projeto, conforme as funcionalidades implementadas.

## 💡 Justificativa

Crianças apresentam diferentes necessidades, preferências e formas de aprender. Por isso, é importante que os ambientes educativos considerem essas diferenças e ofereçam experiências que não dependam de um único ritmo ou método.

O Space Kids foi idealizado para contribuir com essa proposta por meio de recursos digitais que combinam aprendizagem, criatividade, interação e relaxamento.

A plataforma procura tornar as atividades mais acessíveis e agradáveis, evitando uma experiência visual excessivamente carregada e priorizando instruções claras, botões identificáveis e elementos interativos.

O projeto não substitui acompanhamento educacional, psicológico ou terapêutico especializado. Sua finalidade é oferecer recursos digitais complementares de aprendizagem, expressão e bem-estar.

## 👧 Público-alvo

O público-alvo do Space Kids são crianças com diferentes necessidades de aprendizagem, comorbidades e neurodivergências, além de crianças que possam se beneficiar de atividades educativas e interativas apresentadas de maneira simples e acolhedora.

A plataforma também pode ser utilizada por responsáveis e educadores como apoio na exploração das atividades, de acordo com as necessidades de cada criança.

A proposta é respeitar as particularidades dos usuários, oferecendo diferentes tipos de experiências para que cada criança possa explorar os recursos de maneira confortável.

## 🛠️ Tecnologias e ferramentas utilizadas

### HTML5

O HTML é responsável pela estrutura das páginas do Space Kids. Por meio dele, são organizados títulos, textos, botões, formulários, áreas de atividades, menus, vídeos e outros elementos da interface.

Cada página possui uma estrutura própria, permitindo apresentar conteúdos específicos, como jogos educativos, exercícios de respiração e atividades de pintura.

### CSS3

O CSS é utilizado para definir a identidade visual do website e organizar os elementos na tela.

Entre suas responsabilidades estão:

* Definição das cores e dos planos de fundo.
* Escolha das fontes e dos tamanhos dos textos.
* Organização de cartões, botões e áreas de conteúdo.
* Aplicação de bordas arredondadas e sombras suaves.
* Criação de degradês e efeitos visuais.
* Animações de elementos interativos.
* Adaptação do layout para diferentes tamanhos de tela.
* Melhorias visuais de foco e interação.

A identidade visual utiliza uma temática espacial infantil, com cores pastel, como lilás, azul-claro, rosa e verde-menta, além de elementos que remetem ao universo, às estrelas e aos planetas.

### JavaScript

O JavaScript é responsável pelo comportamento interativo das atividades.

Dependendo da página, ele permite controlar respostas de jogos, atualizar elementos visuais, alternar vídeos, processar movimentos de peças, realizar desenhos no canvas e controlar etapas de uma atividade de respiração.

Essa linguagem permite que o site responda às ações realizadas pelos usuários, tornando a experiência mais dinâmica.

### Visual Studio Code

O Visual Studio Code foi utilizado como ambiente de desenvolvimento para escrever, editar e organizar os arquivos HTML, CSS e JavaScript.

### Git e GitHub

O Git permite acompanhar as alterações realizadas no código e manter um histórico de versões. O GitHub permite armazenar o repositório remotamente e facilitar o compartilhamento do projeto.

Essas ferramentas contribuem para a organização do desenvolvimento e para a documentação das etapas realizadas.

## 🧩 Funcionalidades e atividades do Space Kids

O Space Kids reúne diferentes atividades, cada uma com uma finalidade específica. A divisão por páginas permite que os usuários encontrem experiências variadas, sem concentrar todos os recursos em uma única interface.

### 1. 😊 Bolhas de Humor

A página **Bolhas de Humor** foi desenvolvida para permitir que a criança escolha uma opção que represente como está se sentindo.

As opções apresentadas são:

* **Feliz 😊**
* **Calmo 😌**
* **Triste 😢**
* **Animado 🤩**

Quando uma opção é selecionada, o JavaScript atualiza elementos visuais da página, como o emoji apresentado e a cor da bolha. A interface também utiliza efeitos de pulsação e flutuação para tornar a interação mais lúdica.

A atividade oferece uma maneira simples e visual de expressar emoções. Ela pode ser utilizada como ponto de partida para conversas sobre sentimentos, respeitando a forma como cada criança deseja se expressar.

### 2. 🐾 Qual o Animal?

A página **Qual o Animal?** apresenta uma atividade de reconhecimento de animais por meio de elementos visuais e opções de resposta.

O objetivo é incentivar a observação, a associação de informações e o raciocínio de maneira divertida.

A interface apresenta uma área de destaque para o emoji ou elemento visual do desafio, opções para responder e mensagens de retorno que indicam o resultado da tentativa.

A atividade também conta com uma opção para jogar novamente e um recurso para retornar à página anterior.

O CSS organiza os componentes em cartões e áreas de resposta, utiliza cores suaves e adapta o conteúdo para diferentes tamanhos de tela.

### 3. 🎨 Qual a Cor?

A página **Qual a Cor?** apresenta um jogo de reconhecimento de cores.

As alternativas incluem:

* Rosa.
* Azul.
* Verde.
* Amarelo.
* Roxo.

O jogo apresenta uma cor para identificação e permite que a criança escolha uma das alternativas disponíveis.

O JavaScript verifica a resposta selecionada e apresenta um retorno de acerto. Depois da resposta, as opções podem ser desabilitadas até o próximo desafio, evitando novas seleções na mesma rodada.

O botão **Próxima Cor** permite avançar para outra etapa da atividade.

O HTML organiza os elementos da interface, enquanto o CSS utiliza cores pastel, botões interativos e regras de responsividade. Também são utilizados atributos de acessibilidade, como rótulos para determinados controles, para ajudar na identificação dos elementos.

### 4. ➕ Soma e Subtração

A página **Soma e Subtração** apresenta uma proposta de prática de operações matemáticas básicas.

A atividade foi desenvolvida para oferecer uma maneira interativa de explorar cálculos, estimulando o raciocínio lógico e a resolução de problemas.

A estrutura visual organiza o desafio e seus controles para que a criança possa acompanhar a atividade com clareza.

Os comportamentos específicos, como geração de contas, validação das respostas, mensagens de retorno e avanço entre exercícios, dependem da lógica JavaScript implementada na versão da página.

### 5. 🧩 Nebulosa do Silêncio

A página **Nebulosa do Silêncio** apresenta um desafio de organização de peças inspirado no quebra-cabeça deslizante.

A atividade utiliza um tabuleiro de **3 × 3**, no qual as peças precisam ser movimentadas para alcançar a organização esperada.

O jogo trabalha com quatro configurações predefinidas de emojis. A criança pode movimentar uma peça adjacente ao espaço vazio para reorganizar o tabuleiro.

O botão **Novo desafio** permite alternar entre as configurações disponíveis. Quando a organização correta é alcançada, a atividade apresenta uma mensagem de conclusão.

O CSS organiza o tabuleiro e as peças, utilizando bordas arredondadas, cores suaves e efeitos visuais. O JavaScript controla as movimentações, a troca dos desafios e a verificação da conclusão.

A proposta é estimular a atenção, o planejamento e o raciocínio lógico por meio de uma atividade visual.

### 6. 🖌️ Pintura Estelar

A página **Pintura Estelar** oferece uma área de desenho digital para que a criança possa explorar a criatividade livremente.

O principal elemento da atividade é uma área de desenho baseada no elemento HTML `canvas`, configurada com dimensões de referência de **900 × 500 pixels**.

A interface disponibiliza controles para:

* Selecionar a cor do desenho.
* Ajustar o tamanho do pincel.
* Desenhar livremente.
* Utilizar a ferramenta de borracha.
* Limpar a área de desenho.
* Desenhar utilizando mouse ou toque, conforme o suporte implementado.

O JavaScript acompanha os movimentos realizados sobre a área de desenho e utiliza esses movimentos para traçar as linhas.

O CSS organiza o painel de ferramentas, os botões e a área de pintura, mantendo a identidade visual espacial e adaptando a interface para telas menores.

A atividade estimula a criatividade e permite que cada criança utilize as cores e os traços de sua preferência.

### 7. 🌙 Respiro Lunar

A página **Respiro Lunar** apresenta uma atividade de respiração guiada com uma esfera animada.

A proposta é conduzir a criança por etapas visuais de respiração, com instruções e contagem de tempo.

O ciclo planejado utiliza três etapas:

1. Inspirar durante 4 segundos.
2. Segurar a respiração durante 4 segundos.
3. Expirar durante 6 segundos.

O botão **Começar** inicia a atividade. A interface apresenta uma esfera que muda de tamanho para representar visualmente as etapas, acompanhada por uma contagem regressiva.

O CSS controla a aparência da esfera, os efeitos de brilho e a animação. O JavaScript gerencia as etapas, o texto apresentado e a contagem do tempo.

A atividade foi pensada como um recurso simples de pausa e relaxamento. A criança deve poder realizar a atividade de acordo com seu conforto, sem ser pressionada a seguir um ritmo que não seja adequado para ela.

### 8. 🎧 Sons do Cosmo

A página **Sons do Cosmo** integra a proposta de oferecer experiências sonoras relaxantes dentro da temática espacial do projeto.

Seu objetivo é disponibilizar um espaço dedicado a conteúdos sonoros que possam contribuir para uma experiência digital mais tranquila.

A apresentação visual segue a identidade do Space Kids, com cores suaves e elementos que remetem ao universo.

O funcionamento específico da reprodução sonora depende dos elementos HTML e dos controles JavaScript existentes na versão correspondente da página.

### 9. 🎬 Vídeos do Cosmo

A página **Vídeos do Cosmo** oferece opções de vídeos com temáticas tranquilas para complementar as atividades do Space Kids.

As opções apresentadas são:

* **Chuva tranquila:** conteúdo audiovisual com temática de chuva.
* **Ondas do oceano:** conteúdo relacionado ao movimento do mar.
* **Floresta:** conteúdo com temática de natureza.
* **Espaço:** conteúdo relacionado ao universo.

Os vídeos são apresentados por meio de um player incorporado do YouTube, utilizando o elemento HTML `iframe`.

Os botões permitem escolher o conteúdo que será exibido. A função JavaScript `trocarVideo(tipo)` atualiza o endereço do player de acordo com a opção selecionada. O texto que identifica o vídeo em exibição também é atualizado pela lógica da página.

O CSS utiliza um layout responsivo com CSS Grid para organizar as opções, além de estilizar os botões e o player.

Como os conteúdos dependem de uma plataforma externa, a reprodução pode variar conforme a disponibilidade do vídeo, a conexão com a internet e as permissões de incorporação definidas pelo responsável pelo conteúdo.

## 🧑‍💻 Área administrativa

Além das atividades infantis, o projeto prevê uma área administrativa destinada à organização e ao gerenciamento das informações da plataforma.

O fluxo planejado contempla uma tela inicial, acesso por login e uma área administrativa acessível por um botão próprio. Também foram previstos acessos separados para determinadas seções, como Sobre e Atividades, conforme a organização definida para o projeto.

A área administrativa começa após a etapa de acesso e inclui recursos como dashboard, cadastro e gerenciamento de crianças.

### Dashboard

O dashboard funciona como uma tela inicial de administração, reunindo informações gerais em uma interface organizada.

Os cartões e as seções visuais permitem separar informações por categoria e facilitar a localização dos recursos disponíveis.

### Cadastro e gerenciamento de crianças

Essa parte da administração é destinada à organização das informações relacionadas às crianças cadastradas na plataforma.

Os formulários e controles utilizados dependem da implementação da página administrativa e de sua lógica JavaScript.

O gerenciamento de dados de crianças exige cuidados especiais com privacidade, segurança e acesso autorizado. Em uma versão destinada ao uso real, é necessário utilizar mecanismos adequados de autenticação e armazenamento seguro.

### Organização da navegação

A separação das telas e dos acessos procura facilitar a utilização da área administrativa e manter as atividades infantis organizadas.

A aparência das páginas é definida pelo CSS, enquanto o JavaScript controla as interações e os comportamentos implementados para cada seção.

A escolha das cores e dos componentes procura transmitir tranquilidade, acolhimento e diversão, mantendo uma apresentação coerente entre as diferentes páginas.

### Principais características visuais

* **Elementos espaciais:** referência a estrelas, planetas e ao universo.
* **Cartões arredondados:** organização das informações em áreas bem definidas.

* **Botões interativos:** resposta visual às ações realizadas pelo usuário.
* **Animações:** movimentos utilizados em determinadas atividades para representar estados ou tornar a interface mais dinâmica.

O objetivo é criar uma experiência visual agradável sem tornar a interface excessivamente carregada.

## ♿ Acessibilidade e responsividade

A acessibilidade é um aspecto importante para a proposta do Space Kids, pois o projeto foi pensado para crianças com diferentes necessidades.

Entre os recursos utilizados nas páginas estão a organização clara dos elementos, botões identificáveis, instruções diretas, áreas de interação visual e, em determinadas atividades, rótulos de acessibilidade para controles.

A responsividade é trabalhada por meio de regras CSS e consultas de mídia (`@media`), que permitem ajustar o layout para diferentes tamanhos de tela.

Em algumas páginas, também são utilizados estados de foco para facilitar a identificação do elemento selecionado durante a navegação por teclado.

Esses recursos contribuem para a experiência de uso, mas não garantem, isoladamente, conformidade completa com padrões de acessibilidade. O projeto pode ser aprimorado por meio de testes com teclado, leitores de tela, contraste de cores e usuários com diferentes necessidades.

## ▶️ Como executar o projeto

Para executar o Space Kids localmente, siga estas etapas:

### 1. Obter os arquivos

Baixe o projeto ou clone o repositório do GitHub.

git clone URL_DO_REPOSITORIO

Substitua `URL_DO_REPOSITORIO` pelo endereço real do repositório.

### 2. Abrir no Visual Studio Code

Abra o Visual Studio Code e selecione a pasta do Space Kids.

### 3. Verificar os arquivos

Confira se as páginas HTML, os arquivos CSS, os scripts JavaScript e os recursos utilizados pelas páginas estão presentes.

Verifique também se os caminhos utilizados para importar CSS, JavaScript, imagens e outros recursos correspondem à estrutura real das pastas.

### 4. Executar no navegador

Abra a página inicial HTML no navegador. Também é possível utilizar a extensão Live Server do Visual Studio Code, caso esteja instalada, para facilitar a execução durante o desenvolvimento.

### 5. Testar as atividades

Acesse cada página e verifique o funcionamento dos botões, das respostas, das animações e dos recursos interativos.

Na página Vídeos do Cosmo, é necessária uma conexão com a internet para carregar os vídeos externos.

Como o Space Kids é voltado ao público infantil, qualquer versão que armazene informações de crianças deve considerar a proteção de dados desde o planejamento.
